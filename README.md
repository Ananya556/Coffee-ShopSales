# ☕ Coffee Shop Sales Dashboard - README

## 📌 Project Overview

The **Coffee Shop Sales Dashboard** is an interactive Excel-based business intelligence project designed to analyze and visualize coffee shop sales performance. The dashboard provides insights into sales trends, customer purchasing behavior, product performance, store location performance, and order patterns across different months and weekdays. By transforming raw sales data into meaningful visualizations, the dashboard helps management make data-driven decisions to improve profitability and operational efficiency.

---

## 🎯 Problem Statement

Coffee shop businesses generate large volumes of transactional data daily. However, without proper analysis, it becomes difficult to:

* Identify top-performing products.
* Track overall sales performance.
* Understand customer purchasing patterns.
* Analyze peak business hours.
* Compare store performance across locations.
* Monitor order trends by weekdays and months.
* Make informed business decisions based on historical data.

Manual analysis of thousands of transactions is time-consuming and prone to errors, creating a need for an automated and interactive reporting solution.

---

## 💡 Solution

This project addresses the above challenges by creating a dynamic Excel dashboard using Pivot Tables, Pivot Charts, Slicers, and Data Visualization techniques.

The dashboard enables users to:

* Monitor **Total Sales**, **Average Bill**, **Footfall**, and **Average Orders**.
* Analyze **Quantity Ordered by Hour** to identify peak sales periods.
* View **Category-wise Sales Distribution** through pie charts.
* Understand **Size-wise Order Distribution** (Small, Regular, Large).
* Compare **Sales and Footfall Across Store Locations**.
* Identify **Top 5 Products Based on Sales**.
* Analyze **Orders by Weekday** to understand customer behavior.
* Filter reports dynamically using **Month** and **Day** slicers.

---

## 📊 Dashboard KPIs

| KPI           | Description                       |
| ------------- | --------------------------------- |
| Total Sales   | Overall revenue generated         |
| Average Bill  | Average spending per transaction  |
| Footfall      | Total customer visits             |
| Average Order | Average items purchased per order |

---

## 🔍 Key Insights

* Peak ordering hours occur during morning business hours.
* Coffee products contribute the highest percentage of total sales.
* Large-sized beverages are the most preferred by customers.
* Hell's Kitchen store records the highest sales performance.
* Barista Espresso is the best-selling product.
* Weekday sales are generally higher than weekend sales.
